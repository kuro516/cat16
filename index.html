カタチパズル

最初から置かれたブロックを、全部消せばクリア。

パズルのギミックや図形としての面白さを味わう、王道の15ステージです。上から順番に攻略します。クリアすると次のステージが現れます。

    初期配置のない、ふつうの落ちものパズルです。ブロックを積んで消して、ゲームオーバーまで続けます。高いスコアを狙います。

    まだ記録がありません

    落ちてくるミノの順番と数が決まっています。その中で、最初のブロックを全部消してください。最初の「入門」5問でルールに慣れてから、本編に進めます。使うミノが少ないほど星が増えます（★1〜3）。操作はほかのモードと同じです。「戻す」ボタン（Uキー）で一手ずつ戻せます。「ヒント」ボタン（Hキー）を押すと、次に置く場所が光って、操作の回数も表示されます。メインモードと同じく、クリアすると次のパズルが現れます。

      マスをタップ（なぞってもOK）して、最初に置くブロックを描きます。「あそぶ」で、実際のゲームと同じ操作で試せます。下のコードをコピーすると、ほかの人にステージを渡せます。

      ブロック 0 個

      ステージコレクション

      いま描いているステージに名前を付けて保存できます（最大30個、この端末のブラウザに保存）。

        まとめてバックアップ・取り込み

        「まとめてコピー」で全ステージを1つの文章にできます。別の端末では、この欄に貼り付けて「まとめて取り込む」。友だちのコードも、1行ずつ「名前 コード」の形で貼れば取り込めます。

        盤面とミノの順番を決めて、自分でパズルを出題できます。「あそんで確かめる」でクリアできると、そのときの手順がコードに入ります。ほかの人のコードを貼れば、パズルとして遊べます。

        ブロック 0 個

        クリアできました

        コードを受け取って遊ぶ

        友だちのパズルのコードを貼って、「あそぶ」を押します。ヒント・戻す・星は、パズルモードと同じです。

        パズルコレクション

        保存したパズルと、受け取ったパズルです（最大30個、この端末のブラウザに保存）。まとめての控えは、トップの「せってい」の「バックアップ」から取れます。

          AからZまでの26文字に挑戦するモードです。好きな文字から遊べます。落下の速さは変わらないので、落ち着いて形を崩していきましょう。

          クリア済み 0 / 26

            画面のテーマ

            バックアップ

            クリア記録・ステージコレクション・パズルコレクション・せっていを、1つの文章にまとめます。端末を変えるときや、念のための控えにどうぞ。保存先はこのブラウザなので、データを消すと記録もなくなります。

            あそびかた

            ルール

            さまざまな初期配置から始まる落ちものパズルです。最初から置かれているブロックを全部消せばクリア。最初のブロックは中央に小さな点が付いていて、落ちてくるブロックとは色で見分けられます。ノーマルだけは、初期配置のない、ふつうの落ちものパズルです。パズルは、決まった順番と数のミノで、最初のブロックを全部消す詰め将棋のようなモードです。
